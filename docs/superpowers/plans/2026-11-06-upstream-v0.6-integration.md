## Review

An independent reviewer found no critical or important merge-induced regressions. The source and generated release manifest contain only the standard launcher package/HOME role; experimental build flags are gone.

Inherited issues identified during review, left outside this merge: LAN metadata injection can disagree with the offline manifest's index byte count; the fork's offline renderer-crash recovery can leave its WebView absent; upstream video initialization can race an activity pause before page readiness. The tests above verify completed-page video lifecycle, not background initialization or a real-TV renderer crash. These issues were present in the original fork or upstream before this integration.
